# Global Codex Preferences

- Prefer pnpm for JavaScript/TypeScript repositories.
- Read repository-level AGENTS.md before doing work.
- Ask before adding a new production dependency unless repository instructions explicitly authorize it.
- Run available lint, typecheck, tests and build before reporting completion.
- Never expose, print or commit secrets.
- Report exact failed or skipped checks.
- Keep changes scoped to the requested task.
