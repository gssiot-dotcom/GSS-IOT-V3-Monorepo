# Start Here

## Siz qiladigan ish

1. Yangi bo‘sh Git repository yarating.
2. Ushbu starter pack ichidagi barcha fayllarni repository rootiga ko‘chiring.
3. `reference/source-materials/` ichidagi ZIP va MD fayllar mavjudligini tekshiring.
4. Codex projectni shu repository rootdan oching va projectga trust bering.
5. Codexdan instruction sourcesni summarize qilishni so‘rang.
6. `prompts/00_REPOSITORY_BOOTSTRAP.md`ni yuboring.
7. Phase 0 reportini tekshirmasdan Phase 1ga o‘tmang.

## Codex qiladigan ish

- source materialni inspect qiladi;
- yangi monorepo scaffold qiladi;
- quality tooling yaratadi;
- legacy extraction report yozadi;
- keyingi phase uchun state/TODO/decision docsni yangilaydi.
